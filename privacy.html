Privacy Policy

プライバシーポリシー

制定日：2026年9月7日

データ収集なし
端末内のみで利用

日本語

1. 収集するデータ

「ちょうせいちゃん」は、個人情報、カレンダー情報、位置情報、端末情報、利用状況、その他のユーザーデータを収集しません。分析ツールおよび広告SDKも使用していません。

2. カレンダー情報の利用

本アプリは、空き時間の検索と、ユーザーが指定した予定の作成のために、iPhoneのカレンダーへのアクセスを使用します。

  • カレンダー情報は、処理のために端末内でのみ利用されます。
  • カレンダー情報を外部サーバーへ送信しません。
  • カレンダー情報を第三者に提供しません。

3. 外部通信と保存

本アプリは、ユーザーデータを外部サーバーへ送信または保存しません。アカウント登録やログイン機能もありません。

4. ポリシーの変更

本ポリシーを変更する場合は、このページに改定内容と日付を掲載します。

English

1. Data Collection

“Chosei-kun” does not collect personal information, calendar data, location data, device information, usage data, or any other user data. The app does not include analytics or advertising SDKs.

2. Use of Calendar Data

The app requests access to calendars on the iPhone only to find available time slots and to create an event explicitly requested by the user.

  • Calendar data is processed only on the device.
  • Calendar data is never transmitted to an external server.
  • Calendar data is never shared with third parties.

3. External Transmission and Storage

The app does not transmit or store user data on any external server. It has no account registration or sign-in feature.

4. Changes to This Policy

If this policy changes, the revised content and effective date will be posted on this page.
